以下五项从企业微信后台读出后填入，保存时后端会立即用它们换取 access_token，并回报真实连接结果。

企业微信会先请求回调 URL 校验签名，通过后才把客户消息推过来。地址随部署环境变化，请以本页显示的为准。

顺序很重要：先在上面填好五项并「保存并连接」，再去企业微信后台登记这个地址——登记那一刻企业微信就会请求它，校验用的正是你刚保存的回调 Token 与 EncodingAESKey，凭证没保存就去登记会一直验证失败。地址必须是企业微信能访问到的公网 HTTPS 地址；如果你现在是用内网地址打开控制台，这里显示的不是该登记的那一个。

填好上面那项后可以「自检回调地址」：服务端会拿已保存的凭证，按企业微信的方式请求这个地址，并校验它是否原样返回明文。企业微信后台点「保存」之前就能知道登记会不会通过；失败时给出的原因会指明卡在哪一步。这一步会由服务器发起一次真实的外部请求，只对平台超级管理员开放，且只接受 HTTPS 公网地址。
